### A.1 contact-qr.png の減色・軽量化（2026-08-15 / Phase 7）

**背景**: 実質2色（黒／白）のQRコードでありながら、24bit RGB・中間調ノイズ入りで保存されていたため 134,327 バイトあった。`/contact/` の画像はこの1点のみで、ページ重量の大半を占めていた。

**加工内容**

| 項目 | 加工前 | 加工後 |
|---|---|---|
| ファイルサイズ | 134,327 バイト | **963 バイト**（-99.3%） |
| 色空間 / ビット深度 | RGB 8bit/ch（実質グレースケール） | グレースケール 1bit |
| ピクセル寸法 | 480×480 | 480×480（**変更なし**） |
| 階調 | 256階調（中間調が全体の3.2%） | 2階調（0 / 255。コントラスト最大） |

- 手順: Pillow 11.3.0 でグレースケール化し、**しきい値128で2値化**して1bit PNG として再保存した（`optimize=True`）。**リサイズ・トリミング・回転・再エンコード以外の改変はしていない**（モジュールの座標は元画像のまま）。
- しきい値の妥当性: 128 を基準に ±32（96〜160）へ振っても変化する画素は全体の 0.2〜0.5% にとどまり、いずれもモジュール境界のアンチエイリアス部のみだった。しきい値の選び方に結果が左右されない。
- 表示への影響なし: HTML の `width`/`height` 属性（480）、CSS の表示幅（`.method__qr` = 10rem）とも変更していない。

**読み取り検証（必須。CLAUDE.md §3-7）**

`zbarimg` が無いため、macOS 標準の **CoreImage `CIDetector`（QRCode / accuracy High）と Vision `VNDetectBarcodesRequest`** の2系統でデコードし、両者の結果一致を合格条件とした（検証コードは使い捨て。リポジトリには含めない）。

- 加工前・加工後とも `https://forms.gle/F3hhwY17eZTv9k3w9` にデコードされ、**2系統・加工前後の4通りすべてで文字列が完全一致**した。
- 縮小耐性: 320 / 240 / 160 / 120 / 96px へ縮小した状態でも加工前後とも同一文字列にデコードできた（実表示は160px相当のため十分な余裕がある）。
- なお、このQRが指す `forms.gle/F3hhwY17eZTv9k3w9` は、`docs/CONTENT.md` §6.1 記載の `forms.gle/YZ8bPWESxtVHzLJG6` とは短縮URLの文字列が異なるが、**両者とも同一のGoogleフォーム**（`docs.google.com/forms/d/e/1FAIpQLSc-pdK3PH490mL4euo1UtaCJhh9R1GIxPlc6QvjSi59f1G84Q/viewform`）へ302リダイレクトすることを確認済み。**画像の内容は変更していない。**

### asset_id: hero-visual-photo
- 使用セクション: 01 Hero（右カード内、SVG版と差し替え候補）
- 用途: AI活用支援の世界観を伝えるメインビジュアル
- 保存ファイル名: assets/img/hero-visual.webp（受領時は.png可、こちらで変換）
- 推奨形式/AR/解像度: PNG→WebP ／ 4:3 ／ 1600×1200以上
- 背景透過: 不要
- 被写体: 日本のオフィスで、ノートPCの画面を一緒に見ながら作業する2〜3人のビジネスパーソン（30〜40代、服装はビジネスカジュアル）
- 構図: 斜め横からのミディアムショット。画面そのものは見切れてよい（特定UIを描写しない）
- 色調: 暖色寄りの自然光、白・ベージュ基調＋差し色に朱赤（#DE2B1C系）の小物
- 余白: 上部20%に文字を載せないがトリミング耐性のため周囲に余裕を持たせる
- 避けるべき要素: 文字・ロゴ・実在ブランド・SF的演出（ホログラム等）・青系サイバー表現
- プロンプト: 「日本のオフィスで、ノートパソコンの画面を一緒に見ながら笑顔で作業する日本人ビジネスパーソン2〜3人。30〜40代、ビジネスカジュアル。伴走支援・チームワークの雰囲気。明るい自然光、白とベージュ基調の温かみのある色調、差し色に朱赤の小物。斜め横からのミディアムショット、写実的な写真風。文字やロゴは含めない。」
- ネガティブ条件: 文字、ロゴ、ウォーターマーク、青色のサイバー演出、ホログラム、ロボット、過剰な被写界深度、歪んだ手指
- 実装時の表示方法: heroの右カード内 object-fit:cover、角丸（--radius）
