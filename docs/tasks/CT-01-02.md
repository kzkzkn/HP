# Codex Task

Task ID: CT-01 + CT-02
対象ページ: index.html（1ページ完結サイト）
対象セクション: プロジェクト基盤・デザイントークン（CT-01）／ヘッダーとナビゲーション（CT-02）

目的: 静的サイトの骨格とデザイントークンを構築し、ヘッダーを完成させる。

参照デザイン:
- docs/design-spec.md（**必読。トークン・数値はすべてここに従う**）
- docs/content.md（**文言はここから一字一句転記。創作禁止**）
- 世界観: ワイヤーフレーム案C「テック・グリッド」= ライトベース（--paper）×方眼×インクボーダー×赤アクセント。手描き風表現は使わずクリーンに。

使用素材: assets/img/logo-horizontal.png（ヘッダー、高さ36px）

対象ファイル:
- index.html（新規）
- assets/css/style.css（新規）
- assets/js/main.js（新規）

実装要件:
1. index.html: lang="ja"、design-spec/content.mdのメタ情報（title/description）を設定。Google Fonts（Noto Sans JP 400,500,700,900 / IBM Plex Mono 400,500、display=swap、preconnect付き）。本文は header + main + footer 構成。main内に section#hero, #issues, #solution, #service, #reasons, #case, #mission, #company, #contact の空セクション（各セクションにはmonoラベルとH2見出しのみ先行実装、中身は後続タスク）。footerも空でよい。
2. style.css: design-spec「1. デザイントークン」の:root変数をそのまま定義。リセット（box-sizing等）、bodyの背景--paper・文字--ink・フォント設定、.container（max-width:1140px中央、左右padding PC56px/SP20px）、セクション共通padding（PC96px/SP64px）、monoラベル・H2・カード・チップ・ボタン（.btn=accent塗り+ink1.5pxボーダー+pill+オフセット影、.btn-ghost=card背景）の共通クラスを実装。
3. ヘッダー: position:sticky top:0。高さ64px、背景#FFFEF9（rgba 95%+backdrop-filter:blur(8px)）、下ボーダー1.5px var(--ink)。左にロゴ画像（alt="株式会社AIの鉄人"、高さ36px、リンク→#top）、中央〜右にmonoナビ（SERVICE→#service、CASE→#case、COMPANY→#company、CONTACT→#contact）、右端に.btnの「お問い合わせ」（href=GoogleフォームURL、target="_blank" rel="noopener"）。
4. モバイル（≤768px）: ハンバーガーボタン（button要素、aria-label="メニュー"、aria-expanded切替、44px以上）でナビ開閉。main.jsにトグル実装。アンカークリックで閉じる。
5. main.js: ハンバーガートグルのみ（後続でIntersectionObserver追加予定の構造にしておく）。
6. scroll-behavior:smooth と scroll-margin-top:80px、prefers-reduced-motion:reduce 時のsmooth無効化をCSSで。

変更してはいけない箇所: docs/ 配下、assets/img/ 配下、.gitignore、CNAME（存在する場合）

PCでの達成条件（1440px）: ヘッダー64px固定表示、ロゴ・ナビ4項目・CTAボタンが1行に収まり、スクロールしても追従。各セクションの見出しが縦に並ぶ。
スマートフォンでの達成条件（390px）: ハンバーガーメニューが表示され、タップでナビが開閉。横スクロールが発生しない。
